# Next.js Reusable Auth Component

A **reusable authentication system** for Next.js projects featuring:

- Email/password signup & login
- Google OAuth sign-in
- MongoDB integration
- JWT session management
- Easy to reuse across projects

---

## 🛠 Tech Stack

- Next.js (App Router)
- NextAuth.js
- MongoDB / Mongoose
- bcryptjs
- JavaScript (no TypeScript required)

---

## 🚀 Features

- Signup and Login forms
- Google OAuth login
- Password hashing with bcryptjs
- Session management with NextAuth
- Protected routes support
- Fully customizable UI

---

## ⚡ Setup

1. **Clone the repo**
```bash
git clone https://github.com/<your-username>/Next-Auth-Component.git
cd Next-Auth-Component
```

2. **Install dependencies**
```
npm install
```

3. **Create a .env.local file in the root with your keys:**
```
MONGODB_URI=your-mongodb-uri
GOOGLE_CLIENT_ID=your-google-client-id
GOOGLE_CLIENT_SECRET=your-google-client-secret
NEXTAUTH_SECRET=your-random-secret
```
4. **Run the development server**
```
npm run dev
```


5. **Open your browser and go to:**

http://localhost:3000
